# Architecture Decision Records

`NNNN-title.md`, from [the template](../../adlc/templates/adr.md). Status: Proposed → Accepted (human, gate G3) → Superseded / Deprecated. A duplicate that was folded into another ADR before G3 is marked **Withdrawn** and its number is not reused.

Agents write ADRs as **Proposed**. Only a human moves an ADR to Accepted. Cross-stream conflicts found before G3 are recorded in [../consistency-review.md](../consistency-review.md).

Streams: **A** = system context, language, policy engine, tenancy, protocol, providers, local runtime, search. **B** = identity, policy model, Agent Host boundary, gateways. **C** = runtime, audit, telemetry, kill-switch, export, deployment.
